# Host services in the ACP Atom runtime

The Atom runtime is parameterized with a portable **Host services** Layer (`ChildProcessSpawner | FileSystem | OS | Path`). Desktop composes `TauriServicesLive` once at the runtime factory (`createHostRuntime`) into both the Effect Atom runtime (`atomRuntime`) and a `ManagedRuntime` (`hostRuntime`, with `runHost` / `runHostExit` / `runFork`) for Promise-edge React and fire-and-forget Host IO. We rejected injecting the Layer at the React app root (no behavior win) and rejected widening Host services to include ConfigProvider / Observability (those stay desktop-only composition extras outside the portable Seam).
