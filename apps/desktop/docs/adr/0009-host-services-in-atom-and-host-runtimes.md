# Host services in the Atom and Host runtimes

The Atom runtime is parameterized with a portable **Host services** Layer (`ChildProcessSpawner | FileSystem | OS | Path`). Desktop composes `TauriServicesLive` once at the runtime factory (`createHostRuntime`) into both the Effect Atom runtime (`atomRuntime`) and a `ManagedRuntime` (`hostRuntime`, with `hostRun` / `hostRunFork` / `hostRunPromise` / `hostRunPromiseExit` mirroring `Effect.runSync` / `Effect.runFork` / `Effect.runPromise` / `Effect.runPromiseExit`) for Promise-edge React and fire-and-forget Host IO. We rejected injecting the Layer at the React app root (no behavior win) and rejected widening Host services to include ConfigProvider / Observability (those stay desktop-only composition extras outside the portable Seam).
