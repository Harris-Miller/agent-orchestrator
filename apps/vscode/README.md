# Harness Orchestrating Agents

Run and orchestrate coding agents from VS Code. Harness Orchestrating Agents (HOA) adds a sidebar where you start agent sessions, follow their progress, and manage the agent providers you use.

## Getting started

1. Install [Node.js](https://nodejs.org) 22 or newer (with npm). HOA shows a message if either is missing.
2. Open the **Secondary Side Bar** (**View: Toggle Secondary Side Bar Visibility**) and select the **HOA** icon. You can also run **HOA: Focus Sidebar** from the Command Palette.
3. Open **Settings > Providers** in the HOA sidebar and install the agent providers you want. They are downloaded once and shared with the HOA desktop app.

## Commands

| Command              | Description                  |
| -------------------- | ---------------------------- |
| `HOA: Focus Sidebar` | Reveal the HOA sidebar view. |

## Requirements

- VS Code 1.140 or newer
- Node.js 22 or newer and npm
