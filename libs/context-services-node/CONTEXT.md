# context-services-node

Node.js / Bun live layers for `@lib/context-services`.

## Language

**OS live layer**:
The Node/Bun implementation of the OS service (`OSLive`), backed by `process` and `node:os`.
_Avoid_: Node OS, process service

For host vocabulary (`OS`, `Host`), see [`../context-services/CONTEXT.md`](../context-services/CONTEXT.md).
