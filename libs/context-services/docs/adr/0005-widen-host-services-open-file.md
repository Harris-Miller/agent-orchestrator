# Widen Host services with OpenFile

Host services include OpenFile alongside BundledResource, ChildProcessSpawner, Clipboard, FileDialog, FileSystem, OpenUrl, OS, and Path so shared chat UI can open a referenced file in the Host editor without importing a host editor SDK. Surface for this change is `open(path)` (absolute path; the Host opens files and may reveal directories), `openImageData(mimeType, base64)` (image bytes with no file uri, written by the Host to a temp file and opened), and a `supported` flag so callers render file links inert where the Host cannot open them. Every Host declares OpenFile explicitly: the Tauri Live Adapter reports `supported: false` and fails each call until the desktop file explorer lands (#169), rather than shared code reading OpenFile as an optional service. Live Adapters stay in host packages (`@lib/context-services-tauri`, `@lib/context-services-vscode-webview`); only host apps compose those Live Layers into the Host runtime. Chat link classification and dispatch are recorded in the ui ADR `0005-chat-links-via-host-services`.
