# Widen Host services with VscodeExtension

Host services include VscodeExtension so the shared Providers UI can offer to install the Bundled VS Code extension without importing Tauri (see desktop ADR 0019). Surface: `supported`, `bundled` (the `.vsix` path and the Host version it was stamped with, `undefined` when this build did not bundle it), `detect` (a working VS Code CLI, the app without one, or nothing), `installedVersion` and `installBundled`. The Host resolves the CLI and the `.vsix` itself, so callers pass no executable path or arguments. Every Host declares VscodeExtension explicitly: the Tauri Live Adapter calls constrained `src-tauri` commands, and the VS Code webview Live Adapter reports `supported: false` and fails each call (the extension is already running in VS Code), so shared code hides the feature rather than reading the service as optional.
