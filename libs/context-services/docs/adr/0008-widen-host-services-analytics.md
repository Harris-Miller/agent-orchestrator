# Widen Host services with Analytics

Host services include Analytics alongside AtomicFile, BundledResource, ChildProcessSpawner, Clipboard, FileDialog, FileSystem, Notifier, OpenFile, OpenUrl, OS, Path, and VscodeExtension so shared UI can capture product Analytics events without knowing the host or the vendor (root ADR 0004, #451). Surface is a single `capture(event)` returning `Effect<void>` that cannot fail: it is fire-and-forget, and a Live that cannot deliver drops the event. `capture` accepts only the branded `AnalyticsEvent` built by `makeAnalyticsEvent`, which only the `@lib/ui` event catalog calls; properties are `boolean | number | string`. Every Host declares Analytics explicitly. Both Hosts compose the same Live from `@lib/analytics-posthog` (`makeAnalyticsLive(buildTarget, 'desktop' | 'vscode')`, over the Host's fetch-backed `HttpClient`, `OS` and ConfigProvider), so the vendor wire format lives in one package, not in a Host adapter. A prod build, or a dev build with an empty `POSTHOG_PROJECT_TOKEN`, gets `AnalyticsNoopLive` (also the default for tests that do not record). Callers never import a vendor SDK.
